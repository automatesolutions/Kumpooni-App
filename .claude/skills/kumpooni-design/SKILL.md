# /kumpooni-design

Build in the Kumpooni web design system.

1. Read `web/DESIGN.md` (rules) and `web/src/styles/tokens.css` (values) first.
2. Use only the CSS variables from `tokens.css`. Never hard-code a colour, font size, radius or shadow.
3. Reuse classes from `web/src/styles/components.css` and components from `web/src/components/ui.tsx`
   (Button, Dialog, EmptyState, ErrorState, Skeleton, Stepper, Checkbox, Rating, StatusBadge, PageHead).
4. Icons: Iconify Tabler components from `web/src/components/icons.tsx` only (generated by
   `web/scripts/build-icons.mjs`). Do not draw or generate icons, or add another icon set.
   Motion: GSAP via `web/src/lib/gsap.ts`, always behind `MQ.motion`.
5. Every control people tap is at least 44px (`--tap`).
6. Every list has loading, empty and error states.
7. Write all copy with the `/my-tone` skill: sentence case, verb buttons, no banned words.
8. Apply the `/hig` numbers to every screen (tap targets, type sizes, contrast).
9. Check the screen at 375px and 1280px wide, in light and dark mode.
